---

TalkBridge mengubah ponsel atau laptop menjadi juru bahasa saku: Anda berbicara bahasa Mandarin, aplikasi mengucapkannya dalam bahasa Inggris; lawan bicara menjawab dalam bahasa Inggris, aplikasi menerjemahkannya ke Mandarin. Diletakkan di dekat speaker komputer, aplikasi menampilkan subtitel terjemahan langsung untuk video dan rapat daring. Saat rapat, aplikasi merekam audio, membuat transkrip langsung dengan label pembicara dan terjemahan paralel, lalu menyusun notulen, tugas, dan ringkasan bahasa Inggris untuk diekspor atau dikirim lewat LINE. Mode latihan melatih kalimat bisnis dan perjalanan dalam bahasa Inggris, Vietnam, dan Thai dengan penilaian pelafalan serta bermain peran dengan AI. Semua berjalan di peramban dan data tetap di perangkat; fitur AI bersifat opsional dan memakai kunci DeepSeek (bawaan), OpenAI, atau Claude milik Anda. Pembicara dipisahkan otomatis dari suaranya, dan setiap tugas punya penanggung jawab serta tenggat.

12 bahasa README adalah terjemahan dokumentasi. Antarmuka aplikasi saat ini berbahasa Mandarin Tradisional.

## Mulai cepat

1. Buka URL di atas di Chrome/Edge (Windows, macOS, Android) atau Safari (iPhone).
2. Izinkan mikrofon dan pilih kedua bahasa di tab «口譯».
3. Tekan «開始自動口譯» dan bicaralah; terjemahan muncul dan dibacakan.
4. Opsional: masukkan kunci API Anthropic di «設定» untuk notulen AI, terjemahan AI, dan bermain peran.

## Fitur

- Juru bahasa dua arah (deteksi pembicara otomatis atau tekan untuk bicara), 22 bahasa
- Mode subtitel: teks besar, layar penuh, ekspor .srt
- Rapat: rekaman, transkrip, label pembicara (tombol 1–9), terjemahan paralel, notulen dan tugas AI, ekspor .txt/.md/.srt/.json/audio, berbagi ke LINE
- Latihan: 8 skenario × 6 kalimat (Inggris, Vietnam, Thai), penilaian pelafalan, rangkaian harian, bermain peran AI, panduan belajar
