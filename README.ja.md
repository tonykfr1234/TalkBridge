TalkBridge はスマートフォンやノート PC をポケット通訳に変えます。中国語で話せば英語で読み上げ、相手が英語で答えれば中国語に訳します。PC のスピーカーの横に置けば、動画やオンライン会議にリアルタイムで翻訳字幕を表示します。会議では録音、リアルタイム文字起こし、話者ラベル、同時翻訳を行い、終了後に要点・決定事項・ToDo・英語サマリーを作成して書き出しや LINE 共有ができます。練習モードでは英語・ベトナム語・タイ語のビジネス／出張フレーズを発音採点付きで練習でき、AI ロールプレイも利用できます。すべてブラウザで動作し、データは端末内にのみ保存されます。Claude の AI 機能は任意で、ご自身の Anthropic API キーを使います。

12 言語の README はドキュメントの翻訳です。アプリの画面は現在繁体字中国語です。

## クイックスタート

1. PC・Android は Chrome / Edge、iPhone は Safari で上の URL を開きます。
2. マイクを許可し、「口譯」タブで双方の言語を選びます。
3. 「開始自動口譯」を押して話すと、翻訳が表示され読み上げられます。
4. 任意：「設定」に Anthropic API キーを入力すると、AI 議事録・AI 翻訳・AI ロールプレイが使えます。

## 機能

- 双方向通訳（話者の自動判定またはボタン交互）、22 言語
- 翻訳字幕モード：大きな字幕、全画面、.srt 書き出し
- 議事録：録音、文字起こし、話者ラベル（数字キー 1–9）、同時翻訳、AI 要約と ToDo、.txt/.md/.srt/.json/音声の書き出し、LINE 共有
- 語学練習：8 シーン × 6 文（英語・ベトナム語・タイ語）、発音採点、連続日数、AI ロールプレイ、学習ガイド
