---

TalkBridge 把手机或笔记本变成随身口译员：你说中文，它用英文说出来；对方用英文回答，它再翻成中文。放在电脑音箱旁，就能为视频和在线会议实时加上翻译字幕。开会时可以同时录音、实时转写、标记发言人、同步中译英，会后一键整理要点、待办事项与英文摘要，导出或分享到 LINE。练习模式提供英语、越南语、泰语的商务与出差情景句，并对发音评分，还能与 AI 进行情景对话。所有功能在浏览器中运行，数据只保存在你的设备上；AI 功能为可选，可使用你自己的 DeepSeek（默认）、OpenAI 或 Claude 密钥。会议中会依声音自动区分发言人，待办事项都会写明负责人与截止日期。

12 种 README 语言是文档翻译，App 界面目前使用繁体中文。

## 快速开始

1. 电脑或 Android 用 Chrome / Edge，iPhone 用 Safari 打开上方网址。
2. 允许麦克风，在「口譯」页选择双方语言。
3. 按「開始自動口譯」开始说话，翻译会显示并朗读。
4. 可选：在「設定」填入 Anthropic API 密钥，启用 AI 会议要点、AI 翻译与 AI 情景对话。

## 功能

- 双向口译（自动检测说话方或按键轮流），22 种语言
- 翻译字幕模式：大字幕、全屏、导出 .srt
- 会议记录：录音、实时转写、发言人标记（数字键 1–9）、同步翻译、AI 要点与待办、导出 .txt/.md/.srt/.json/音频、分享到 LINE
- 语言练习：8 个情景 × 6 句（英语、越南语、泰语），发音评分、连续练习天数、AI 情景对话、学习方法
