TalkBridge는 휴대폰이나 노트북을 휴대용 통역사로 바꿉니다. 중국어로 말하면 영어로 읽어 주고, 상대가 영어로 답하면 중국어로 번역합니다. 컴퓨터 스피커 옆에 두면 동영상과 온라인 회의에 실시간 번역 자막을 띄웁니다. 회의에서는 녹음, 실시간 받아쓰기, 화자 표시, 동시 번역을 하고, 끝나면 요점·결정 사항·할 일·영어 요약을 만들어 내보내거나 LINE으로 공유합니다. 연습 모드에서는 영어·베트남어·태국어 비즈니스/출장 문장을 발음 점수와 함께 연습하고 AI 역할극도 할 수 있습니다. 모든 기능은 브라우저에서 실행되며 데이터는 기기에만 저장됩니다. AI 기능은 선택 사항이며 본인의 DeepSeek(기본), OpenAI 또는 Claude 키를 사용합니다. 회의에서는 목소리로 화자를 자동 구분하고, 할 일마다 담당자와 마감일을 적습니다.

12개 언어 README는 문서 번역이며, 앱 화면은 현재 번체 중국어입니다.

## 빠른 시작

1. PC·Android는 Chrome / Edge, iPhone은 Safari로 위 주소를 엽니다.
2. 마이크를 허용하고 「口譯」 탭에서 두 언어를 고릅니다.
3. 「開始自動口譯」을 누르고 말하면 번역이 표시되고 읽힙니다.
4. 선택: 「設定」에 Anthropic API 키를 넣으면 AI 회의록, AI 번역, AI 역할극을 쓸 수 있습니다.

## 기능

- 양방향 통역(화자 자동 판별 또는 버튼 교대), 22개 언어
- 번역 자막 모드: 큰 자막, 전체 화면, .srt 내보내기
- 회의록: 녹음, 받아쓰기, 화자 표시(숫자 키 1–9), 동시 번역, AI 요약과 할 일, .txt/.md/.srt/.json/오디오 내보내기, LINE 공유
- 언어 연습: 8개 상황 × 6문장(영어·베트남어·태국어), 발음 점수, 연속 학습일, AI 역할극, 학습 가이드
