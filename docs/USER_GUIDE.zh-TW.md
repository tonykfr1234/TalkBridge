# TalkBridge 語橋 使用說明

## 1. 開啟與安裝

- 電腦（Windows／macOS）與 Android：用 **Chrome** 或 **Edge** 開啟 App 網址。
- iPhone／iPad：用 **Safari** 開啟，並在「設定 → 一般 → 鍵盤」開啟「聽寫」。
- 第一次使用會詢問麥克風權限，請選「允許」。不小心拒絕時，點網址列左邊的鎖頭圖示重新允許。
- 安裝成 App：電腦版在網址列右側點「安裝」，或到 App 的「設定 → 安裝到主畫面」；iPhone 在 Safari 分享選單選「加入主畫面」。

語音辨識與翻譯需要網路。沒有網路時仍可開啟 App、查看已儲存的會議。

## 2. 口譯（面對面對話）

1. 在「我說」和「對方說」選好兩種語言，⇄ 可以交換。
2. **自動偵測**：按「開始自動口譯」，中文、英文不限順序，想說哪種就說哪種。
   - **有 OpenAI 金鑰（建議）**：到「設定 → AI 服務」選 OpenAI 貼上金鑰。App 會依說話停頓切出每一句，交給 OpenAI Whisper 辨識，它會自己判斷這句是中文還是英文，準確度最高。每句說完後約 1–2 秒出現翻譯，費用約每分鐘語音 0.006 美元。
   - **沒有金鑰（免費）**：App 一直用中文辨識器收音。Google 的中文辨識器聽到英文句子通常會直接寫成英文，App 再依文字判斷語言並翻譯。如果英文常被聽成奇怪的中文字，請改用 OpenAI 金鑰或「按鍵輪流」。
   - 口譯畫面按鈕上方會顯示目前用哪一種辨識。
3. **按鍵輪流**：兩人各一個按鈕，按下自己那一邊再說話，說完再按一次停止。兩種語言都使用拉丁字母時（例如英文和西班牙文）建議用這個模式。
4. 也可以在下方輸入框打字翻譯。
5. 每個泡泡都可以點喇叭重聽或複製。

**選擇聲音**

- 口譯頁「自動唸出翻譯」旁邊可選「我的話用：女聲／男聲／我的聲音」與「對方的話用：女聲／男聲」，兩邊用不同聲音比較好分辨。
- 有 OpenAI 金鑰時，女聲、男聲用 OpenAI 線上語音，比較自然；沒有金鑰時用裝置內建語音。
- **我的聲音（聲音克隆）**：到「設定 → 我的聲音」：
  1. 填入 ElevenLabs API 金鑰（elevenlabs.io 註冊，聲音克隆需付費方案，入門方案約每月 5 美元）。
  2. 按「開始錄音」，照畫面上的中英文稿子唸約 1 分鐘（至少 30 秒），在安靜的地方錄效果最好。
  3. 播放確認，勾選「這是我本人的聲音，我同意」，按「建立我的聲音」。
     - 建立中：按鈕下方出現橘色進度框，顯示步驟和已等待秒數，通常 10–30 秒。卡片標題旁的狀態是「建立中…」。
     - 完成：出現綠色「✓ 你的聲音已建立好」和建立時間，並自動用你的聲音唸一句英文。標題旁狀態變成「✓ 已建立」，口譯頁按鈕變成「我的聲音 ✓」。
     - 失敗：出現紅色框，寫出原因（包括 ElevenLabs 的原始回覆，例如方案不支援聲音克隆），修正後按「再試一次」。
  4. 回到口譯頁，「我的話用」會自動切到「我的聲音」：你說中文，翻成英文後就是你的聲音在說英文。
  5. 不想用時按「刪除我的聲音」，會從 ElevenLabs 移除。
- 只能克隆你本人的聲音，請勿錄製或上傳他人的聲音。

小技巧：朗讀翻譯時 App 會暫停收音，避免把自己的聲音再翻一次。不需要朗讀時可以取消「自動唸出翻譯」。

## 3. 字幕（替影片、線上會議上字幕）

1. 選「聽到的語言」（例如英文）和「翻成」（例如中文）。
2. 把手機或筆電放在電腦喇叭旁，按「開始字幕」。
3. 按「全螢幕」可以把字幕放大到整個畫面；手機可以橫放。
4. 結束後按「下載字幕檔 (.srt)」，可以匯入影片剪輯軟體或播放器。

**讓電腦直接聽系統聲音（效果最好）**

Windows 11／10 有「立體聲混音」時：

1. 按 Win＋R，輸入 `mmsys.cpl` 按 Enter，會打開傳統的「聲音」視窗。也可以從「設定 → 系統 → 音效」往下捲到「進階」，點「更多音效設定」。
2. 切到「錄製」分頁，在裝置清單的空白處按右鍵，勾選「顯示已停用的裝置」。
3. 對「立體聲混音」（Stereo Mix）按右鍵 →「啟用」。
4. 在 Chrome 網址列輸入 `chrome://settings/content/microphone`，把上方的麥克風下拉選單改成「立體聲混音」。這樣比改 Windows 預設裝置更可靠，因為 Chrome 不一定使用 Windows 的預設麥克風。
5. 回到 App 按「開始字幕」。用完記得把 Chrome 麥克風改回原本的，否則口譯和會議會聽不到你說話。

找不到「立體聲混音」（很多筆電的音效驅動不提供）時，用免費的 VB-Audio Virtual Cable：

1. 到 vb-audio.com/Cable 下載安裝，裝完重新開機。
2. 按工作列右下角的喇叭圖示，把輸出裝置選成「CABLE Input」。這時喇叭會暫時沒聲音。
3. 讓自己也聽得到：在 `mmsys.cpl` 的「錄製」分頁，對「CABLE Output」按右鍵 →「內容」→「接聽」分頁 → 勾選「接聽此裝置」，「透過此裝置播放」選你的喇叭或耳機 → 確定。
4. Chrome 麥克風（同上第 4 步）選「CABLE Output」。
5. 不用時把輸出裝置改回喇叭，Chrome 麥克風改回原本的。

macOS：安裝 BlackHole，在「音訊 MIDI 設定」建立包含喇叭和 BlackHole 的「多重輸出裝置」並設為輸出，Chrome 麥克風選 BlackHole。

## 4. 會議記錄

**開會時**

1. 選「會議語言」，需要時選「同步翻譯成」（例如英文，就會每句中翻英）。
2. 勾選「同時錄音」可保留原始錄音檔。
3. 「自動分辨發言人」預設開啟：每一句話會依聲音（音色、音高）自動分給發言人 1、2、3…，不用手動點。
4. 按「開始記錄」。上方計時器與音量表顯示收音狀態。
5. **改成真名**：每位發言人旁邊有「✎ 改名」，按下去輸入名字（例如「王經理」）按 Enter，逐字稿和待辦裡的名字會一起換掉。會後也可以到「發言分析」頁，一次把所有發言人改名，每一列都附一句他說過的話方便辨認。
6. **認錯人時**：點上方的發言人按鈕，就會把「最新一句」改成那個人；之後的句子會跟著學。也可以在逐字稿每句前面的下拉選單直接改。
7. 想自己標記時，取消「自動分辨發言人」，改用點選或鍵盤數字 **1–9** 切換目前說話的人。
8. 可以「暫停」，結束時按「結束並儲存」。結束時 App 會用整場的聲音資料再分析一次發言人，比開會中更準。會議會自動存在這台裝置。

**讓自動分辨更準的小技巧**

- 把手機或筆電放在桌子中間，讓每個人離麥克風差不多遠。
- 一次一個人說話；多人同時說話時，那一句只會分給其中一位。
- 會議開始時請每個人簡短自我介紹（「我是業務部的王經理」），App 能更快分出不同的人，AI 整理時也會把「發言人 1」自動換成真名。
- 聲音很像的兩個人可能被併成同一位。在逐字稿改正幾句後，到「發言分析」按「依聲音重新分析發言人」。手動改過的句子不會被覆蓋。

**會後**

- **逐字稿**：每一句都可以直接點文字修改，或從下拉選單改發言人；點時間碼可以從那個位置播放錄音。
- **重點備忘**：「AI 整理重點」會產生摘要、重點、決議、待確認問題與英文摘要（需要 AI 金鑰）。最重要的是**待辦事項**表：
  - **負責人**：會議中講到的人名；沒講名字時，用承諾或被指派的那位發言人，並標「（推斷）」。
  - **期限**：把「明天、下週五、月底、11月5日、by Friday」換算成實際日期與星期，例如「10/30（五）・下週五」。
  - **優先**：高／中／低；下方小字是這項待辦出自哪一句話。
  - 沒有講到負責人或期限的，會以紅字顯示「未指定負責人」「未指定期限」，提醒你會後追問。
  - 下方「依負責人」把每個人要做的事列在一起，方便直接傳給對方。
  - 「離線快速整理」不用金鑰，也會找出可能的待辦、人名和日期，但準確度比 AI 低。
- **發言分析**：每位發言人的發言比例；「依聲音重新分析發言人」用整場聲音資料重新分組；「AI 依內容建議發言人」依問答與自我介紹等線索建議每句是誰說的。
- **匯出與分享**：
  - 下載 `.txt` 逐字稿、`.md` 會議記錄、`.srt` 字幕、`.json` 完整資料、錄音檔。
  - 手機按「分享檔案」會跳出系統分享選單，選 LINE 就能把逐字稿、會議記錄和錄音傳到聊天室。
  - 「用 LINE 傳送重點」會開啟 LINE 分享畫面，傳送摘要和待辦文字。
  - 電腦版 LINE 不支援網頁分享，請先下載檔案再拖進聊天室。

右側「以前的會議」列出這台裝置上的所有紀錄。清除瀏覽器資料會一併刪除，重要會議請記得匯出。

## 5. 語言練習

1. 選語言：英文、越南文、泰文（人工撰寫的句子）；日文、韓文、印尼文（即時翻譯產生）。
2. 選情境：自我介紹、商務會議、談判報價、電話視訊、工廠採購、商務餐敘、交通飯店、購物殺價。
3. 每一句：
   - 🔊 播放標準發音，🐢 慢速播放；
   - 🎤 跟著說，系統會比對並給 0–100 分，紅色波浪線是沒被聽到或說錯的字；
   - 85 分以上記為「已熟練」，情境卡片會顯示進度。
4. 泰文可切換男生（ครับ）或女生（ค่ะ／คะ）的口吻。
5. **AI 情境對話**：選好情境後 AI 會扮演對方（例如供應商、飯店櫃台），你用目標語言回答（可打字或按麥克風），每一回合都會看到中文翻譯、拼音，以及對你上一句的修正建議。
6. **學習方法**：各語言的聲調、稱謂與禮貌用語重點，以及每天 15 分鐘的練習流程。

沒有聲音時：代表裝置沒有該語言的語音。Windows：設定 → 時間與語言 → 語音 → 新增語音；Android：設定 → 文字轉語音 → 安裝語音資料。

## 6. 設定

- **AI 服務**：選 **DeepSeek**（預設）、**OpenAI** 或 **Claude**，貼上該服務的 API 金鑰，按「測試金鑰」確認。三家的金鑰分開保存，可以隨時切換。
  - DeepSeek：在 platform.deepseek.com 建立金鑰並儲值，預設模型 `deepseek-chat`。
  - OpenAI：在 platform.openai.com 建立金鑰，預設模型 `gpt-4.1-mini`，可在模型欄輸入其他名稱。
  - Claude：在 console.anthropic.com 建立金鑰，預設 Claude Opus 5.5（最準確），也可選 Sonnet 5.5 或 Haiku 5.5。
  - 用量會計入你自己的帳戶，建議在各家主控台設定每月上限。
  - App 不會內建任何人的金鑰：網站是公開的，寫在程式裡的金鑰任何人都能複製去用。
- **翻譯引擎**：免費網路翻譯（快）或 AI 翻譯（用上面選的 AI 服務，語氣自然，適合商務，較慢）。
- **語音**：調整朗讀速度、試聽。
- **外觀**：跟隨系統、淺色、深色。
- **這台裝置支援的功能**：列出語音辨識、朗讀、錄音、分享檔案、離線開啟是否可用。

## 7. 隱私

- 會議錄音、逐字稿、練習進度只存在這台裝置的瀏覽器。
- 自動分辨發言人在瀏覽器內計算，聲音不會因此上傳。
- 語音辨識由瀏覽器處理（Chrome 會送到 Google，Safari 送到 Apple）。
- 翻譯會把文字送到翻譯服務；使用 AI 功能時，會把相關文字用你的金鑰送到 Anthropic。
- API 金鑰只存在這個瀏覽器，在共用電腦用完請到設定按「清除金鑰」。
